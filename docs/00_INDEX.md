## Scope of this repo

This is the **public GitHub Pages static site** for the Pack Fábrica de Agentes offer (IDEA-006.F1).

content, full decision log, and internal strategy live in the private repo**
[`idea-006-fabrica-de-agentes`](https://github.com/EngineeringGuild/idea-006-fabrica-de-agentes) and
in `project-money` (the IDEA-006 umbrella). The docs below (`01`–`06`) cover only what's specific to
